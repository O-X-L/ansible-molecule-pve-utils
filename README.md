# Ansible-Molecule PVE-Driver - Util Modules

This repository holds Ansible Collection of Util-Modules for the Ansible-Molecule Proxmox-VE Driver.

## Proxmox-VE Driver for Ansible-Molecule

For more infos see: [the Main repository](https://github.com/O-X-L/ansible-molecule-pve) or [the Documentation](https://ansible-molecule-pve.oxl.app)

## Install

```bash
ansible-galaxy collection install oxlorg.molecule_pve

# or
ansible-galaxy collection install git+https://github.com/O-X-L/ansible-molecule-pve-utils.git
```
